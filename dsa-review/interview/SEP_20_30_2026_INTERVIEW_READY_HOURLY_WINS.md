## Fixed rules for every session

1. **Cold first.** Read the problem statement, start the timer, and attempt before opening a solution, pattern trigger, course, or prior code. A DSA rep is `WHAT → DERIVE → CODE → TEST/DEBUG → EXPLAIN`, with the [7-day sheet's G1/G2/Y/R scoring](./DSA_7-Day_Hourly_WIN_FINAL_v15_HighSignal_Pattern_Triggers.md). One independent green rep beats five watched solutions.
2. **One gap, one repair.** Log `Score; Where I broke; Missing piece; Closed-book retry; Next due date`. Repair the highest-impact miss first. Stop at the time boundary even when the work feels unfinished.
3. **Applications count as preparation.** A saved job link is not an application. A win is a submitted, relevant application, a referral request actually sent, or a follow-up actually sent. Use the exact job-link workflow below; do not force a poor-fit application.
4. **No debt.** Missed blocks are skipped, not carried into nights or doubled on weekends. Protect work, sleep, exercise, and social time from the weekly table you shared. Monday and Tuesday are deliberately light.
5. **Sources have jobs.** [LRU cache](../../../../LLDProjects/lru-cache/README.md) and [pre-trade risk engine](../../../../LLDProjects/pre-trade-risk-engine/README.md) are LLD reference answers **after** an attempt. [Trading risk platform](../../../../SystemDesignProjects/trading-risk-platform/README.md) and [notification platform](../../../../SystemDesignProjects/notification-platform/README.md) are HLD reference material, not projects to rebuild this month. [MocksPractice](../../../../MocksPractice/README.md) is the mock workflow. Educative and AlgoMonster are lookup tools for a diagnosed gap, not new completion targets.
6. **Repair order when several things went wrong:** first a gap in the next confirmed interview's format; otherwise a failure that prevented working code; then an incorrect design invariant/data flow; then weak communication. If still tied, use DSA → LLD → HLD → Java/story. Repair only the first item in the available block. This rule also orders the maximum three September carry-forward gaps.
