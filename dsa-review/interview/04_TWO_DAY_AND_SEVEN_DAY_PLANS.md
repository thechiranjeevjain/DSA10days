# Two-Day And Seven-Day Plans

Use this when a company asks for a DSA round soon. The goal is interview triage: remove red flags first, then expand coverage by rank.

Core files: [Zero To Hero Ranked Table](01_ZERO_TO_HERO_RANKED_TABLE.md), [One-Line Recall](02_ONE_LINE_RECALL_ALL_PROBLEMS.md), [Crisp Interview Answers](03_CRISP_INTERVIEW_ANSWERS.md), [Pattern Files](patterns/README.md), [Pre-Zoom RAM Cache](../notes/PRE_ZOOM_INTERVIEW_RAM_CACHE.md), [Post-7-Day Extension Plan](10_AFTER_7_DAY_EXTENSION_PLAN.md).

## If You Have 2 Hours

- Read `00_PATTERN_RECOGNITION_80_20.md` once.
- Speak ranks 1-20 from [One-Line Recall](02_ONE_LINE_RECALL_ALL_PROBLEMS.md) without opening Java.
- Code 2 problems from blank: one HashMap/Two Pointers/Sliding Window, one Linked List/Tree.
- Read [Pre-Zoom RAM Cache](../notes/PRE_ZOOM_INTERVIEW_RAM_CACHE.md) in the last 10 minutes.

## If You Have 1 Day

- Cover Phase 1 from [Zero To Hero Ranked Table](01_ZERO_TO_HERO_RANKED_TABLE.md): ranks 1-30.
- Skim ranks 31-40 if Phase 1 recall is stable.
- Implement 4 problems from blank: one HashMap/Two Pointers, one Sliding Window, one Linked List, one Tree/Graph.
- For each unsolved problem, speak the crisp answer instead of rereading code.

## If You Have 2 Days

- Day 1: Phase 1, ranks 1-30. Code 4 problems from blank.
- Day 2: Phase 2, ranks 31-70. Code 3 problems from blank, then review all one-line recalls.
- Mark every miss as again or hard in the review system.

## If You Have 1 Week

- Days 1-2: Phase 1, then code weak items from blank.
- Days 3-4: Phase 2, then code weak items from blank.
- Day 5: Phase 3 plus weakest pattern file.
- Day 6: mock interview, two random Priority A/B drills.
- Day 7: pre-Zoom cache, one-line recall, and no-blunder review.
- After Day 7: continue with [Post-7-Day Extension Plan](10_AFTER_7_DAY_EXTENSION_PLAN.md) only if ranks 1-100 are mostly GREEN and ranks 1-50 have no repeated RED.

## What Not To Do

- Do not reread Java first. Speak the approach before opening code.
- Do not jump to DP/Trie/Union-Find before Phase 1 and Phase 2 are stable.
- Do not treat the ranking as universal truth. It is an interview-ROI order for fast prep.
- Do not keep a miss invisible. Mark it `again` or `hard` and revisit it.
