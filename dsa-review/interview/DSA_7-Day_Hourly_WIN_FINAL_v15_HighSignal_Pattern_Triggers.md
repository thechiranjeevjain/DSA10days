# DSA 7-Day Interview Sprint — Final Clean

> **Priority:** anytime-stop interview ROI first; dependency order breaks close calls. Earlier scheduled problems are intentionally more important.

## Rules

- First attempt: problem statement only. Check Pattern Trigger and Hint only after the attempt.
- Pattern Trigger = **recognition cue** (why this pattern should fire). Hint = **implementation nudge** (how to start).
- Each coding/review hour: three 18-minute reps, then a 6-minute break. Exact clock times are written in every study row.
- Each 18-minute rep: `WHAT → DERIVE → CODE → TEST/DEBUG → EXPLAIN`.
- GREEN means: independently derive, write runnable Java, test normal/boundary/tricky cases, state time/space complexity, and explain the invariant.
- If stuck: score it and move on. In the repair hour, relearn only the missing piece, close the reference, then reconstruct from blank.
- Review: `R/G2 → D+1`, `Y → D+2`, `G1 → D+7`.
- Notes are blank on purpose. After an attempt, write only: `Score; Stuck; Gap; Fix; Next`.
- Scores: `G1` first-pass GREEN · `G2` GREEN after repair · `Y` partial weakness · `R` major failure / lookup needed.
- Failure codes: `P` pattern · `I` invariant · `D` data structure · `J` Java · `E` edge case · `C` complexity · `B` debugging · `M` memorized/not understood.

## Weekly Output

- Day 1: 18 new hands-on + 3 repair/transfer reps.
- Days 2–6: 3 due recalls + 15 new hands-on + 3 repair/transfer reps.
- End of Day 6: top 93 problems have received hands-on attempts.
- Day 7: recall + mocks + repair + mutations; no coverage chasing.
